1. 기본 원칙

담콩 다이어리(이하 "앱")는 사용자의 기록을 사용자 기기와 사용자 본인의 구글 드라이브에만 저장합니다. 앱 개발자는 별도의 서버를 운영하지 않으며, 사용자의 일기·할 일·가계부·구글 계정 데이터를 수집하거나 전송받거나 보관하지 않습니다. 광고, 사용 통계·분석 도구를 쓰지 않으며, 어떤 데이터도 판매하거나 제3자에게 제공하지 않습니다.

2. 앱이 다루는 정보와 쓰임

일기·할 일·가계부

  • 사용자가 직접 쓴 일기(글, 사진, 스티커, 손글씨), 할 일, 가계부 내역은 기기 안의 앱 폴더에 저장됩니다.
  • 구글 계정에 로그인하면, 같은 내용이 사용자 구글 드라이브의 'DamkongDiary' 폴더에도 저장되어 사용자의 PC·휴대폰 사이에서 동기화됩니다.

구글 계정 정보 (Google 사용자 데이터)

  • 이메일 주소: 어떤 계정이 연결되어 있는지 화면에 보여 주기 위해서만 읽습니다.
  • 구글 드라이브 (drive 권한): 사용자 드라이브의 'DamkongDiary' 폴더를 만들고, 그 폴더 안의 일기 파일을 읽고 쓰는 데에만 사용합니다. PC와 휴대폰이 서로 올린 파일을 읽어야 하므로 이 권한을 요청합니다. 그 밖의 드라이브 파일은 열거나 읽거나 바꾸지 않습니다.
  • 구글 캘린더 (calendar.readonly 권한, 사용자가 캘린더 계정을 추가한 경우에만): 그 계정 기본 캘린더의 일정(7일 전~90일 뒤)의 제목·시각·장소·설명·알림 설정을 읽어 앱의 할 일로 만드는 데에만 사용합니다. 캘린더를 바꾸거나 일정을 만들지 않습니다.
  • 로그인 정보(갱신 토큰)는 기기 안에만 암호화해 저장합니다 (PC: Windows 사용자 계정 보호, 휴대폰: 안드로이드 보안 저장소).

문자·알림 (안드로이드, 사용자가 켠 경우에만)

  • 문자(SMS·MMS·채팅 메시지): 카드 결제 문자에서 결제 카드, 결제 시각, 금액, 사용처만 읽어 가계부에 기록합니다. 문자 원문은 저장하거나 기기 밖으로 보내지 않습니다.
  • 알림 읽기: 결제 알림 글자에서 같은 정보만 읽어 기록합니다. 다른 알림 내용은 저장하지 않습니다.
  • 이 기능은 언제든 앱의 가계부 화면이나 휴대폰 설정에서 끌 수 있습니다.

앱 잠금

  • 비밀번호는 그대로 저장하지 않고, 되돌릴 수 없는 암호값(해시)으로만 기기 안에 저장합니다.
  • 지문 인식은 안드로이드 시스템이 처리하며, 앱은 지문 정보를 받지 않습니다.

3. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구 사항을 포함하여 해당 정책을 준수합니다.

  • Google 사용자 데이터는 위 2번에 적힌, 사용자에게 보이는 기능을 제공하는 데에만 사용합니다.
  • Google 사용자 데이터를 개발자나 제3자에게 전송하지 않습니다 (사용자 본인의 기기와 본인 드라이브 사이의 동기화만 합니다).
  • 광고, 신용 평가, 데이터 판매에 사용하지 않습니다.
  • 사람이 Google 사용자 데이터를 열람하지 않습니다.

4. 보관 기간과 삭제

  • 기록은 사용자가 앱에서 지우거나 앱을 삭제할 때까지 사용자 기기에 남아 있습니다.
  • 구글 드라이브의 기록은 드라이브의 'DamkongDiary' 폴더를 지우면 삭제됩니다.
  • 앱의 구글 접근 권한은 앱에서 로그아웃하거나, 구글 계정 → 서드파티 앱 및 서비스에서 '담콩 다이어리' 접근을 삭제하면 바로 끊깁니다.
  • 캘린더 계정은 앱에서 [빼기]를 누르면 연결이 끊기고, 가져온 할 일도 함께 지울 수 있습니다.

5. 아동의 개인정보

앱은 개인정보를 수집하지 않으며, 만 14세 미만 아동을 대상으로 한 별도의 정보 수집도 하지 않습니다.
